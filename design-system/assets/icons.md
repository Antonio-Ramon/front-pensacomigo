# Iconography — Pensa Comigo

No brand icon set was provided. We use **Lucide** (linear, thin-stroke, rounded) via CDN.

## Load (in a card / kit / consumer HTML)
```html
<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.min.js"></script>
<script>lucide.createIcons();</script>
```
Then use `<i data-lucide="search"></i>` and call `lucide.createIcons()` after render.

## Common glyphs
search, menu, x, plus, chevron-down, chevron-right, arrow-left,
heart (likes), eye (views), share-2, message-circle (comments),
grip-vertical (drag handle), more-horizontal (block actions),
image, link, type (text block), bold, italic, underline, list, list-ordered,
quote, code, calendar, user, tag, upload-cloud, trash-2, pencil.

Social (share): instagram, twitter, linkedin, facebook.

## Rules
- Size 18–20px, color `--text-muted`; `--accent-600` when active.
- No literal religious iconography (crosses, doves, stained glass).
- No emoji.

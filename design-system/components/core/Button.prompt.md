Action button — use for any call-to-action; primary=teal fill, warm=terracotta fill, secondary=outline, ghost=text-only.

```jsx
<Button variant="primary" size="md">Publicar</Button>
<Button variant="warm">Apoiar</Button>
<Button variant="secondary">Cancelar</Button>
```
Variants: primary | warm | secondary | ghost. Sizes: sm | md | lg. Supports disabled.
